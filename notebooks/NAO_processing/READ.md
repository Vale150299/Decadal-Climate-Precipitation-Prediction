# NAO Processing Notebooks

##  Description

This folder contains Jupyter notebooks used to compute the NAO (North Atlantic Oscillation) index from climate model data.

The workflow is organized in sequential steps, from data preparation to index computation.

---

##  Notebooks

### 1. `01_load_and_prepare_model_data_NAO.ipynb`

* Loads CanCM4 model data (sea level pressure - PSL)
* Preprocesses and structures the dataset
* Prepares inputs for NAO index computation

---

### 2. `02_compute_NAO_model_index.ipynb`

* Computes the NAO index using a box-based method:

  * Azores region
  * Iceland region
* Calculates ensemble mean and anomalies
* Outputs processed results

---

##  Output Data

The results generated by these notebooks are saved in:

```
data/models_nao_index/
```

Main output file:

```
data/models_nao_index/can4_nao_index_results.csv
```

👉 This file contains the computed NAO index and anomalies and is used for further analysis and modeling.

---

##  Workflow

1. Run:

```
01_load_and_prepare_model_data_NAO.ipynb
```

2. Then run:

```
02_compute_NAO_model_index.ipynb
```

3. Output is automatically stored in:

```
data/models_nao_index/
```
